#   5 - Publish Artifact to Repository


# 📖 Summary

Worked on **Publish Artifact to Repository (Lab 5)**, focusing on **artifact management, Maven and Gradle builds, and Nexus repository configuration**.
Tasks included configuring user roles and permissions in Nexus, setting up Gradle and Maven projects to publish artifacts, and deploying Java build files to Nexus repositories to solve the challenge of centralized artifact storage and version control.
Set up **Sonatype Nexus repository and Gradle/Maven build tools** to automate and optimize artifact publishing, aiming to streamline the CI/CD pipeline, enhance collaboration, and ensure secure, consistent deployment of software packages.

---

# 🛠️ Tools Used

* **Sonatype Nexus Repository**: ✨ *Used as a centralized artifact repository for storing and managing Java build artifacts.*
* **Gradle**: ⚙️ *Configured with `maven-publish` plugin to build and publish Java artifacts to Nexus.*
* **Maven**: 🚀 *Configured with `maven-deploy-plugin` and distribution management to deploy snapshot builds to Nexus.*

---

# 🎯 Skills Gained

* **Nexus Repository Management**: 💡 *Learned to create users, roles, and configure repositories in Nexus for secure artifact storage.*
* **Gradle Publishing**: 🔍 *Gained hands-on experience setting up Gradle’s `maven-publish` plugin and publishing Java artifacts.*
* **Maven Deployment**: 🚀 *Developed skills configuring Maven’s `pom.xml` and `settings.xml` for automated deployment to Nexus snapshots.*

---

# ⚠️ Challenges Faced

* **Role and Privilege Configuration in Nexus**: 🛠️ *Overcame by carefully defining user roles with proper permissions to enable secure artifact publishing.*
* **Build Tool Authentication**: 🔄 *Solved by securely managing credentials in Gradle properties and Maven settings.xml to authenticate with Nexus.*

---

# 💡 Why It Matters

This lab strengthens expertise in **DevOps and software artifact management**, demonstrating how tools like **Nexus, Gradle, and Maven** improve software delivery through centralized storage and automated deployment.
Mastering these skills supports efficient, reliable CI/CD practices essential in modern DevOps and cloud roles, ensuring teams can collaborate on builds securely and consistently. 🚀🌐
